# KB-ACCESS-01 — Access rights requests

## Standard procedure
1. Verify the user's identity and department via `rechercher_utilisateur`.
2. Verify that the request matches the scope of their department (an access
   request outside the usual scope requires validation from a manager).
3. Any change to access rights is a sensitive action: it always requires
   human validation before being applied, even for a simple request to
   access a shared folder.

## Special case
An unrequested removal of rights (e.g. "my rights were removed by mistake")
must be treated as a potential security incident and verified before any
automatic reassignment.
